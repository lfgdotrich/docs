---
title: Token ABI
description: Runtime ABI for official LFG.RICH tokens.
---

Use this ABI as a copy-paste-ready JavaScript/TypeScript constant with Viem, Ethers, bots, dashboards, and custom integrations.

<Note>
This is the deployed runtime ABI for connecting to the existing Token contract. Constructor entries are not needed when creating `ethers.Contract`, `viem` contract calls, or Web3.py contract objects for an already-deployed contract.
</Note>
