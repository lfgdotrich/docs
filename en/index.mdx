## What makes LFG.RICH different

LFG.RICH tokens are not simple tokens launched into a creator-controlled liquidity pool. Each official token is connected to protocol logic that manages pricing, reserves, floors, fees, and borrowing.

Core mechanics include:

- **Bonding-curve trading** for official LFG.RICH tokens.
- **Protocol-managed reserves** instead of creator-owned LP liquidity.
- **Floor price protection** designed to prevent the token price from falling below its protocol floor.
- **Floor boost mechanics** powered by part of the token's trading fee.
- **Collateral borrowing** where users can lock tokens and borrow BNB against floor value.
- **Developer-accessible data** through public API endpoints and on-chain contract calls.

## Network

LFG.RICH runs on **BNB Smart Chain**.

Users need BNB for gas, token creation transactions, buys, sells, borrowing, and repayments.
