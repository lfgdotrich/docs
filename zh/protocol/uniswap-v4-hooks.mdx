LFG.RICH 使用 Uniswap V4 Hook 架构，让官方代币从发行开始就由协议管理。

Hook 是核心协议合约，负责 bonding-curve 交易、储备记账、地板价逻辑、floor boost 记账、抵押借贷和还款流程。

## 合约角色

| 合约角色 | 用途 |
| --- | --- |
| Factory | 创建官方 LFG.RICH 代币，并将它们注册到 Hook。 |
| Uniswap V4 Hook | 处理定价、地板、储备、手续费、抵押品、借贷和 Hook 回调。 |
| Swap Router | 为用户和集成方提供简单的 `buy` 和 `sell` 函数。 |
| Token | 由 Factory 创建的 ERC20 兼容代币合约。 |
| Pool Manager | Hook 和 Router 流程使用的 Uniswap V4 Pool Manager。 |

## 官方代币如何注册

当创作者发行代币时：

<Steps>
  <Step title="Factory 部署代币">
    Factory 使用选定的名称和符号创建新的 ERC20 兼容代币。
  </Step>
  <Step title="Factory 锁定代币 Hook">
    Factory 在代币上调用 `setHook(address)`。该操作只能执行一次。
  </Step>
  <Step title="Factory 创建 Pool Key">
    Factory 为原生 BNB 和新代币构建 Uniswap V4 pool key。
  </Step>
  <Step title="Hook 注册代币">
    Factory 在 Hook 上调用 `registerToken(token, poolId, totalFeeBps)`。
  </Step>
  <Step title="Pool 初始化">
    Factory 使用协议初始平方根价格初始化 Uniswap V4 pool。
  </Step>
</Steps>

## Hook 的职责

Hook 负责：

- 买入和卖出计算。
- 买入时铸造代币。
- 卖出时销毁代币。
- 收取创作者选择的交易手续费。
- 将固定平台手续费发送到 Factory。
- 将剩余交易手续费分配到 floor boost。
- 跟踪 `realETH`、`virtualETH`、`floorPrice`、`floorBoostPool` 和总储备数据。
- 锁定借贷抵押品。
- 还款时解锁抵押品。
- 更新地板价和历史最高价格记账。

## 为什么禁止添加流动性

LFG.RICH 的官方发行不使用创作者管理的流动性仓位。

Hook 会拒绝普通外部添加流动性操作，确保官方代币机制始终由协议的 bonding curve、储备和地板逻辑控制。
