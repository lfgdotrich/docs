LFG.RICH 是运行在 BNB Smart Chain 上的代币发行平台，内置绑定曲线交易、上涨型地板价保护、代币抵押借贷和推荐奖励机制。

当前协议版本是 **V5**。V5 引入了新的 Hook 架构、固定费率模型、OTOInvite 推荐系统以及更新后的合约交互流程。V3 代币仍然存在，但 V3 已属于旧版/弃用版本，不建议新的集成继续使用。

## 你可以做什么

- 创建官方 LFG.RICH 代币，填写名称、符号、Logo、简介和链接。
- 创建代币时可选择进行一次初始买入。
- 通过 LFG.RICH V5 绑定曲线买入和卖出官方代币。
- 锁定代币作为抵押品，并按协议地板价借出 BNB。
- 绑定邀请人并参与推荐系统。
- 使用公开 API 和链上合约构建看板、机器人、提醒和数据分析工具。
- 将 LFG.RICH Telegram 买入机器人添加到社区群组。

## 网络

LFG.RICH 运行在 **BNB Smart Chain**。用户需要 BNB 支付 Gas、创建代币、买入、卖出、借款和还款。

## 开发者说明

新的集成应使用 **V5 合约**和 V5 交互流程。不要硬编码旧的 PoolKey。对于每个代币，应尽量读取代币自身的 `FACTORY()` 和 `hook()`，然后从正确的 Factory 获取 PoolKey，再执行买卖操作。
