LFG.RICH 是一个带有内置协议机制的代币 Launchpad：包括 bonding curve 交易、地板价保护、由手续费推动的地板增长，以及基于抵押品的 BNB 借贷。

平台面向创作者、交易者、社区和开发者，适合希望代币发行从一开始就具备更强链上机制的项目。

## LFG.RICH 有什么不同

LFG.RICH 代币不是简单地进入由创作者控制的流动性池。每一个官方代币都连接到协议逻辑，由协议管理定价、储备、地板价、手续费和借贷。

核心机制包括：

- 官方 LFG.RICH 代币使用 **bonding-curve 交易**。
- 使用 **协议管理的储备**，而不是创作者持有的 LP 流动性。
- **地板价保护**，用于防止代币价格跌破协议地板。
- **Floor boost 机制**，由部分交易手续费驱动。
- **抵押借贷**，用户可以锁定代币并基于地板价值借出 BNB。
- 通过公共 API 和链上合约调用提供 **开发者可访问的数据**。

## 网络

LFG.RICH 运行在 **BNB Smart Chain**。

用户需要 BNB 来支付 Gas、创建代币、买入、卖出、借贷和还款交易。
