---
title: V3 到 V5 迁移说明
description: V5 发布后开发者需要注意的变化。
---

V5 是 LFG.RICH 当前协议版本。V3 仍为旧代币存在，但新的集成应默认使用 V5。

## 变化内容

| 领域 | V3 / 旧文档 | V5 / 当前文档 |
| --- | --- | --- |
| 代币创建 | 创建者选择交易费 | 固定 V5 费用模型和可选初始买入 |
| 交易 | 旧 Factory/Router/Hook 部署 | 当前 V5 Factory、Hook 和 SwapRouter |
| 推荐 | 未完整记录 | OTOInvite 推荐系统 |
| 价格 | 旧精度假设 | V5 价格按 1e22 缩放 |
| 借贷 | 旧费用/地板价文档 | V5 3% 借贷费和直接父级借贷奖励 |
| 兼容 | 硬编码合约假设 | 动态解析代币 Factory/Hook 和 PoolKey |

## 动态代币上下文

旧代币可能通过 `FACTORY()` 和 `hook()` 返回旧 Factory 或 Hook 地址。新的集成应读取这些值，并在存在时使用它们。

## 不要硬编码 PoolKey

硬编码 PoolKey 可能导致交易失败，因为 PoolManager 需要精确匹配已初始化的池。始终使用正确的 Factory 调用 `getPoolKey(tokenAddress)`。

## V5 价格缩放

V5 价格按 `1e22` 缩放。如果集成将 V5 价格除以 `1e18`，代币价格、市值、借贷预估和 PnL 可能会高出 10,000 倍。
