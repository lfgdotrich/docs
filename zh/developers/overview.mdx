本节面向围绕 LFG.RICH 构建看板、交易工具、机器人、提醒、分析和钱包集成的开发者。

## V5 是当前集成目标

新的集成应使用 V5 合约。V3 只用于旧代币兼容，应视为弃用版本。

## 核心集成流程

代币交互不要硬编码旧 Factory、Hook 或 PoolKey。请按以下流程：

1. 尽量读取代币的 `FACTORY()` 和 `hook()`。
2. 使用正确的 Factory 调用 `getPoolKey(token)`。
3. 用返回的 PoolKey 通过 SwapRouter 买入/卖出。
4. 使用代币的 Hook 和 poolId 进行预估、借贷、还款和价格读取。

## 价格精度

V5 价格类数值按 `1e22` 缩放：

- `getEffectivePrice(poolId)`
- `floorPrice`
- `allTimeHighPrice`
- V5 买卖事件中的 `newPrice`

显示每个代币的 BNB 价格：

```ts
const priceBnb = Number(priceScaled) / 1e22;
```

不要把 V5 价格当作 `1e18` 价格，否则集成显示的价格会高出 10,000 倍。
