## 常见集成场景

- 代币发行仪表盘。
- 买入/卖出报价工具。
- Telegram 和 Discord BuyBot。
- 投资组合和抵押品仪表盘。
- 借贷仓位追踪。
- 协议分析。
- 自定义交易界面。

## 主要集成合约

| 合约 | 用途 |
| --- | --- |
| Factory | 查找官方代币、代币信息、pool ID 和 pool key。 |
| Uniswap V4 Hook | 读取协议状态并估算买入、卖出和 borrowMore。 |
| Swap Router | 通过简单面向用户的方法执行买入和卖出。 |
| Token | ERC20 交互、授权、余额和抵押品授权。 |
