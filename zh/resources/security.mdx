LFG.RICH 是智能合约平台。用户和开发者在与合约交互或构建集成前，应理解相关风险。

## LFG.RICH 设计上想降低的风险

LFG.RICH 通过以下方式降低常见发行风险：

- 协议管理的储备。
- Bonding-curve 交易。
- 地板价保护。
- 永久的创作者选择交易手续费。
- 基于地板价值的抵押借贷。

这些机制旨在让官方发行更透明，并更能抵抗传统流动性 rug 机制。

## 仍需谨慎的方面

没有任何智能合约平台可以消除所有风险。

用户仍应考虑：

- 智能合约风险。
- 前端风险。
- RPC/provider 风险。
- 钱包签名风险。
- 链/网络风险。
- 市场风险。
- 第三方工具集成漏洞。

## 合约验证

检查合约地址时，请使用官方 LFG.RICH 链接和 API。

开发者在集成真实价值前，应验证地址和字节码。

## 更安全的集成实践

- 尽可能从应用 API 读取合约地址。
- 先使用只读调用。
- 发送真实价值前先模拟交易。
- 使用保守的滑点限制。
- 正确处理失败或 reverted 的交易。
- 永远不要要求用户提供助记词或私钥。
