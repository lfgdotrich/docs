官方 LFG.RICH BuyBot 帮助社区直接在 Telegram 群组中跟踪 LFG.RICH 代币的实时活动。

Bot 用户名：

```txt
@lfgdotrich_buybot
```

该机器人跟踪 **BNB Smart Chain** 上的官方 LFG.RICH 代币，并可以在被跟踪代币出现新的买入或借贷活动时在群组中发送提醒。

## 将机器人添加到群组

1. 打开 Telegram 并搜索 `@lfgdotrich_buybot`。
2. 将机器人添加到你的 Telegram 群组。此操作必须由群主，或拥有添加管理员权限的管理员完成。
3. 通过授予机器人管理员权限，确保机器人可以在群组中发送消息。
4. 在群组中运行 `/settoken`。
5. 选择群组语言。
6. 当机器人要求时，发送 LFG.RICH 代币合约地址。

代币地址必须是有效的 BSC 合约地址，并且必须属于在 LFG.RICH 上创建的代币。

<Info>
群组设置必须由群主，或拥有添加管理员权限的群组管理员完成，因为机器人需要管理员权限才能在群组中发送提醒。如果 Telegram 没有在群组中显示机器人的命令，也可以使用带用户名的命令，例如 `/settoken@lfgdotrich_buybot`。
</Info>

## 跟踪代币

运行：

```txt
/settoken
```

机器人会要求你选择语言，然后要求输入代币合约地址。

示例代币地址：

```txt
0x29Ede1E1254419Fe5a3c803fC2b015042075A49A
```

添加代币后，机器人会开始在群组中跟踪该代币的新活动。

## 命令

| 命令 | 谁可以使用 | 作用 |
| --- | --- | --- |
| `/start` | 任何人 | 显示欢迎消息。 |
| `/help` | 任何人 | 显示可用命令列表。 |
| `/settoken` | 群组管理员 | 向群组添加 LFG.RICH 代币跟踪器。 |
| `/deltoken` | 群组管理员 | 从群组中移除被跟踪代币。 |
| `/tokens` | 任何人 | 列出群组当前跟踪的代币。 |
| `/price` | 任何人 | 显示被跟踪代币的当前价格、地板价和 24 小时变化。 |
| `/info` | 任何人 | 显示被跟踪代币的详细信息。 |
| `/lang` | 群组管理员 | 更改群组的机器人语言。 |

## 实时提醒

当被跟踪代币出现新活动时，机器人可以在群组中发送提醒。

买入提醒包括：

- BNB 数量。
- 代币数量。
- 买家钱包简写。
- 当前代币价格。
- 市值。
- 池内金额。
- 交易链接。
- LFG.RICH 代币页面链接。

借贷提醒包括：

- 借出的 BNB 数量。
- 抵押代币数量。
- 借款人钱包简写。
- 交易链接。
- LFG.RICH 代币页面链接。

## 价格信息

使用：

```txt
/price
```

机器人会显示群组中每个被跟踪代币的价格信息，包括：

- 当前代币价格（USD 和 BNB）。
- 地板价。
- 24 小时价格变化。

## 详细代币信息

使用：

```txt
/info
```

机器人会显示群组中每个被跟踪代币的详细信息，包括：

- 价格。
- 地板价。
- 市值。
- 池内金额。
- 24 小时成交量。
- 24 小时交易数。
- 持有人数量。
- 24 小时价格变化。
- 代币页面图表链接。

## 移除代币

运行：

```txt
/deltoken
```

机器人会显示当前被跟踪的代币，并让群组管理员选择要移除的代币。

## 语言

运行：

```txt
/lang
```

机器人当前支持英文和中文群组消息。
