官方 LFG.RICH BuyBot 帮助社区直接在 Telegram 群组中跟踪 LFG.RICH 代币的实时活动。

Bot 用户名：

```txt
@lfgdotrich_buybot
```

该机器人跟踪 **BNB Smart Chain** 上的官方 LFG.RICH 代币，并可以在被跟踪代币出现新的买入或借贷活动时在群组中发送提醒。

<Info>
BuyBot 是信息和通知工具。它不会替用户交易，不会要求私钥，也不需要钱包权限。
</Info>

## BuyBot 可以做什么

BuyBot 可以帮助代币社区：

- 在 Telegram 群组中跟踪一个或多个官方 LFG.RICH 代币；
- 当用户买入被跟踪代币时发送实时买入提醒；
- 当用户使用被跟踪代币进行借贷时发送借贷提醒；
- 显示当前价格信息；
- 显示地板价信息；
- 显示市值、池内金额、24 小时成交量、24 小时交易数、持有人数量和图表链接；
- 支持英文和中文群组消息。

## 开始前需要准备

你需要：

- 一个 Telegram 群组；
- 添加机器人到群组的权限；
- 给机器人管理员权限的权限，这样机器人才能发送消息；
- 想要跟踪的 LFG.RICH 代币合约地址。

代币地址必须是有效的 BSC 合约地址，并且必须属于在 LFG.RICH 上创建的代币。

## 将机器人添加到群组

1. 打开 Telegram。
2. 搜索 `@lfgdotrich_buybot`。
3. 将机器人添加到你的 Telegram 群组。
4. 给机器人管理员权限，确保它可以发送消息。
5. 在群组中运行 `/settoken`。
6. 选择群组语言。
7. 当机器人要求时，发送 LFG.RICH 代币合约地址。

<Info>
群组设置必须由群主，或拥有添加管理员权限的群组管理员完成，因为机器人需要管理员权限才能在群组中发送提醒。
</Info>

如果 Telegram 没有在群组中显示机器人的命令，可以使用带用户名的命令：

```txt
/settoken@lfgdotrich_buybot
```

## 跟踪代币

运行：

```txt
/settoken
```

机器人会要求你选择语言，然后要求输入代币合约地址。

示例代币地址：

```txt
0x29Ede1E1254419Fe5a3c803fC2b015042075A49A
```

添加代币后，机器人会开始在群组中跟踪该代币的新活动。

<Warning>
只使用官方 LFG.RICH 代币合约地址。不要发送交易哈希、pair 地址、poolId 或随机复制的地址。
</Warning>

## 命令

| 命令 | 谁可以使用 | 作用 |
| --- | --- | --- |
| `/start` | 任何人 | 显示欢迎消息。 |
| `/help` | 任何人 | 显示可用命令列表。 |
| `/settoken` | 群组管理员 | 向群组添加 LFG.RICH 代币跟踪器。 |
| `/deltoken` | 群组管理员 | 从群组中移除被跟踪代币。 |
| `/tokens` | 任何人 | 列出群组当前跟踪的代币。 |
| `/price` | 任何人 | 显示被跟踪代币的当前价格、地板价和 24 小时变化。 |
| `/info` | 任何人 | 显示被跟踪代币的详细信息。 |
| `/lang` | 群组管理员 | 更改群组的机器人语言。 |

## 实时提醒

当被跟踪代币出现新活动时，机器人可以在群组中发送提醒。

### 买入提醒

买入提醒包括：

- BNB 数量；
- 代币数量；
- 买家钱包简写；
- 当前代币价格；
- 市值；
- 池内金额；
- 交易链接；
- LFG.RICH 代币页面链接。

### 借贷提醒

借贷提醒包括：

- 借出的 BNB 数量；
- 抵押代币数量；
- 借款人钱包简写；
- 交易链接；
- LFG.RICH 代币页面链接。

借贷提醒来自 LFG.RICH 协议活动，仅用于信息展示，并不代表 BuyBot 在替任何人借贷或交易。

## 价格信息

使用：

```txt
/price
```

机器人会显示群组中每个被跟踪代币的价格信息，包括：

- 当前代币价格（USD 和 BNB）；
- 地板价；
- 24 小时价格变化。

地板价是协议数据。对于 LFG.RICH V5 代币，地板价由 Uniswap V4 Hook 维护，并基于代币 ATH 的地板价逻辑。

## 详细代币信息

使用：

```txt
/info
```

机器人会显示群组中每个被跟踪代币的详细信息，包括：

- 价格；
- 地板价；
- 市值；
- 池内金额；
- 24 小时成交量；
- 24 小时交易数；
- 持有人数量；
- 24 小时价格变化；
- 代币页面图表链接。

## 列出被跟踪代币

使用：

```txt
/tokens
```

这会显示当前 Telegram 群组中正在跟踪的代币。

## 移除代币

运行：

```txt
/deltoken
```

机器人会显示当前被跟踪的代币，并让群组管理员选择要移除的代币。

## 更改语言

运行：

```txt
/lang
```

机器人当前支持英文和中文群组消息。

## 排查问题

### Telegram 中没有显示命令

使用带机器人用户名的命令：

```txt
/settoken@lfgdotrich_buybot
```

同时确认机器人仍在群组内，并且拥有发送消息的权限。

### 机器人不发送提醒

检查以下内容：

1. 已经通过 `/settoken` 添加代币。
2. 地址是代币合约地址，不是交易哈希、pair 地址或 poolId。
3. 该代币是在 LFG.RICH 上创建的。
4. 机器人有权限在群组中发送消息。
5. 添加代币之后确实发生了新的买入或借贷活动。

### 代币地址被拒绝

请确认你是从 LFG.RICH 代币页面或官方来源复制的代币合约地址。机器人只跟踪官方 LFG.RICH 代币。
