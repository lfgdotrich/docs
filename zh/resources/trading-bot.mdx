LFG.RICH Community Trading Bot 是一个用于 BNB Smart Chain 的 Python 交易机器人示例，通过官方 LFG.RICH 协议合约交易 **官方 LFG.RICH 发射台代币**。

此版本仅兼容 **LFG.RICH**：

- 通过 LFG.RICH **Swap Router** 买入；
- 通过 LFG.RICH **Swap Router** 卖出；
- 根据 LFG.RICH Uniswap V4 Hook 的 `Buy` 和 `Sell` 事件构建 K 线；
- 使用 LFG.RICH **Uniswap V4 Hook** 获取价格和报价估算；
- 不使用 PancakeSwap V2；
- 不使用 PancakeSwap V3；
- 不执行 borrow、borrow more 或 repay。

<Warning>
这是社区交易软件。请使用专用钱包，从小金额开始，并在使用真实资金前充分测试。
</Warning>

## 机器人如何工作

机器人从 `config.yaml` 监控一个或多个 LFG.RICH 代币。

对于每个配置的代币，它会：

1. 通过 LFG.RICH Hook 解析代币池；
2. 扫描 Hook 的 `Buy` 和 `Sell` 事件；
3. 构建内部价格 K 线；
4. 计算 EMA、RSI、趋势、pump、dump 和 bleed 等指标；
5. 判断应该 `BUY`、`SELL` 还是 `HOLD`；
6. 如果没有启用 `dry_run`，通过 LFG.RICH Swap Router 执行交易；
7. 将已确认交易和 lots 写入本地 SQLite 数据库。

机器人必须解析并使用代币的 LFG.RICH 池数据。它不应该假设存在传统 pair 地址或 PancakeSwap 风格的池。

## SQLite 数据库和 lots

机器人使用本地 SQLite 数据库：

```text
state.db
```

它会在机器人运行时自动在项目根目录创建。

### 仪表盘依赖机器人

仪表盘读取 `state.db`。

仪表盘本身不交易，也不会自己创建仓位。它依赖机器人创建和更新交易、仓位和 lots。

如果机器人还没有确认任何买入交易，仪表盘可能没有 open lots 可显示。

### 什么是 lots？

**lot** 是机器人对买入仓位的本地记录。

当机器人确认成功买入交易后，会记录一个 lot，包含：

```text
symbol
buy transaction
quantity opened
cost in BNB
average entry price
remaining open quantity
```

仪表盘使用 open lots 计算：

- 当前仓位价值；
- 未实现 PnL；
- 卖出后的已实现 PnL；
- 平均入场价；
- 每个代币的 open exposure。

对于 LFG 代币，仪表盘按以下优先级为 open lots 定价：

1. 最新有效 K 线收盘价；
2. LFG Hook `getEffectivePrice(poolId)` fallback；
3. 前两者都不可用时才为零。

### 常用 SQLite 命令

```bash
sqlite3 state.db ".tables"
sqlite3 state.db "SELECT * FROM trades ORDER BY id DESC LIMIT 10;"
sqlite3 state.db "SELECT * FROM lots ORDER BY id DESC LIMIT 10;"
```

除非你明确想重置本地交易历史、lots、冷却时间和 K 线缓存，否则不要删除 `state.db`。

## 配置参考

本节说明 `config.yaml` 中的设置。

### `chain`

| 设置 | 说明 |
| --- | --- |
| `chain.name` | 可读的链名称。保持为 `bsc`。 |
| `chain.chain_id` | BNB Smart Chain 主网 chain ID。保持为 `56`。 |

### `rpc`

| 设置 | 说明 |
| --- | --- |
| `rpc.request_timeout_sec` | 单个 RPC 请求的超时时间（秒）。 |
| `rpc.max_retries` | RPC 调用失败时的重试次数。 |
| `rpc.backoff_sec` | 重试之间的初始延迟。重复失败时，重试逻辑会增加延迟。 |

### `lfg`

| 设置 | 说明 |
| --- | --- |
| `lfg.factory` | LFG.RICH Factory 合约。用于协议元数据和手续费接收者引用。 |
| `lfg.hook` | LFG.RICH Uniswap V4 Hook。用于事件、代币状态、价格和估算。 |
| `lfg.swap_router` | LFG.RICH Swap Router。用于执行买入和卖出。 |
| `lfg.pool_manager` | LFG.RICH 协议使用的 Uniswap V4 Pool Manager。 |

### `bot` 执行设置

| 设置 | 说明 |
| --- | --- |
| `bot.polling_interval_sec` | 每次机器人循环之间的秒数。 |
| `bot.trade_cooldown_sec` | 同一代币交易后再次交易前等待的秒数。 |
| `bot.min_hold_minutes` | 正常卖出逻辑可以卖出 lot 前的最短持有分钟数。 |
| `bot.dry_run` | 如果为 `true`，机器人只记录计划交易，不发送交易。 |
| `bot.warmup_approve` | 如果为 `true`，机器人启动时检查代币对 LFG Swap Router 的 allowance。 |
| `bot.approve_wait_sec` | 在继续卖出执行前，等待授权交易确认的秒数。 |

### `bot` 风险和交易规模

| 设置 | 说明 |
| --- | --- |
| `bot.profit_gate_enabled` | 如果为 `true`，普通卖出需要满足 `min_profit_pct`，除非触发止损。 |
| `bot.min_profit_pct` | 启用 profit gate 时，普通卖出所需的最低利润百分比。 |
| `bot.max_loss_pct` | 止损百分比。例如 `10` 表示 lot 亏损 `-10%` 或更多时卖出。 |
| `bot.max_hold_minutes` | 可选强制退出时间（分钟）。`0` 表示禁用。 |
| `bot.slippage_bps` | 滑点容忍度，单位为基点。`1200` 表示 12%。它必须覆盖代币手续费和波动。 |
| `bot.gas_limit` | LFG 买入/卖出交易使用的 gas limit。 |
| `bot.min_bnb_for_gas` | 保留用于 gas 的 BNB。机器人不会花掉低于该数值的 BNB。 |
| `bot.min_trade_bnb` | 买入/卖出动作的最低 BNB 金额。 |
| `bot.max_trade_bnb` | 单次买入/卖出动作的最高 BNB 金额。 |

### `bot` 事件扫描和 K 线

| 设置 | 说明 |
| --- | --- |
| `bot.blocks_per_candle` | 每根内部价格 K 线包含的 BSC 区块数。 |
| `bot.confirmations` | 在将事件视为足够安全/最终前等待的区块数。 |
| `bot.log_chunk_blocks` | `eth_getLogs` 的区块分块大小。如果公共/免费 RPC 限速或失败，可降低此值。 |

| `bot.max_history_candles` | 每个代币在内存/缓存中保留的最大 K 线数。 |

### `bot` 策略设置

| 设置 | 说明 |
| --- | --- |
| `bot.fast_down_enabled` | 启用快速下跌卖出保护。 |
| `bot.fast_down_candles` | 用于快速下跌检测的最近真实成交 K 线数量。 |
| `bot.fast_down_min_drop_pct` | 在 `fast_down_candles` 范围内触发快速下跌的最小跌幅百分比。 |

### `bot` test mode

| 设置 | 说明 |
| --- | --- |
| `bot.test_mode` | 如果为 `true`，强制使用 `test_action`，而不是策略信号。适合测试真实买入/卖出。 |

| 设置 | 说明 |

## 排查问题

### 出现 `/usr/lib/python2.7/...` 的 `SyntaxError`

你正在使用 Python 2。

激活 venv 并使用 Python 3：

```bash
source .venv/bin/activate
python --version
python -m bot.main
```

### `ModuleNotFoundError: No module named 'web3'`

当前环境没有安装依赖：

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### `ensurepip is not available`

安装 venv 包：

```bash
apt install -y python3.8-venv python3-pip
```

然后重新创建 venv：

```bash
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate
```

### `pip: command not found`

安装 pip：

```bash
apt install -y python3-pip
```

### `No matching distribution found for aiohappyeyeballs==2.6.1`

你正在使用来自较新 Python 环境的旧/冻结依赖列表。

请使用 LFG.RICH 机器人包中包含的 `requirements.txt`。

### `No matching distribution found for streamlit==1.40.2`

使用包含以下固定版本的 `requirements-dashboard.txt`：

```text
streamlit==1.40.1
```

### `invalid argument 0: hex string without 0x prefix`

请使用最新的 LFG.RICH 机器人包。LFG pool id 和事件 topic 处理已更新，会规范化为带 `0x` 前缀的值。

### 仪表盘显示 `lot_pnl_pct` 为空或 `None`

仪表盘需要有效的当前价格。

对于 LFG 代币，仪表盘现在使用：

1. 最新有效 K 线收盘价；
2. LFG Hook `getEffectivePrice(poolId)` fallback；
3. 前两者都不可用时才为零。
